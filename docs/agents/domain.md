# Domain documents

This repository has one domain context. Read `CONTEXT.md` when designing or naming product concepts. Keep it a glossary. Use `notes/launch-scope.md` for the approved launch behavior and `notes/console-design.md` for the console experience.

Architectural decisions belong in `docs/adr/` when they preserve a consequential tradeoff. Source inspection and historical proposals are evidence, not overrides of the agreed scope.
