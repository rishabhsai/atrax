# Tarantula — YC Audit & Competitive Research

*Prepared 2026-07-26. Research covers the agent-native cloud landscape, the Mac VM market, and YC's current funding appetite (batches W25–W26, Fall 2026 RFS cycle).*

---

## Verdict

**Keep Tarantula, drop the Mac VM idea.** Tarantula's thesis is literally a current YC Request for Startups — **"A Cloud for Small Software" by Pete Koomen (Fall 2026 RFS, ycombinator.com/rfs)**:

> "Using agents to build personal software to solve your own problems is a lot of fun. This is 'Small Software'... Software like this is now very easy to build, but still hard to deploy and share. Incumbent clouds like Azure and AWS were designed for shipping Big Software... A cloud designed for small software could delete most of this complexity... every company will want to customize the environment this software runs in, auth & permissions are hard, and allowing nontechnical users to share arbitrary code is tricky to do securely. **Small software should be as easy to share with your colleagues as a Google Doc.**"

Two problems, both fixable:
1. The space is the most crowded shelf in YC (~41.5% of W26 was agent-infrastructure plumbing).
2. Product depth doesn't yet match marketing surface (six named products on the site, one built).

## Market validation (the demand is real and public)

- Vercel: ~30% of deployments now involve coding agents, up 1000% in six months, ~75% of that Claude Code (vercel.com/blog/agentic-infrastructure).
- Supabase: >60% of new databases created by AI tools; Claude Code the largest single contributor (CNBC, June 2026 — $500M Series F at $10.5B).
- Complaint genre is established: "Vibe Coding Ends at Localhost" (HackerNoon); agents "got brilliant at writing code and stayed useless at deploying it."
- Every major cloud shipped MCP servers + llms.txt in 2025–26; Netlify invented a discipline ("Agent Experience"/AX) around it; Vercel and Railway independently landed on "deterministic surfaces"/"dry-run modes" language.

### The unclaimed whitespace

Nobody models **the whole small app — hosting + database + auth + files + jobs — as one declared, versioned unit that an external coding agent can plan against, deploy, inspect, and drift-check via stable JSON.**

Core argument: **MCP servers and llms.txt are discovery mechanisms — probabilistic, unversioned, mutable. A versioned contract is a reliability mechanism.** Agents operating unattended need determinism; nobody sells determinism. Sell the contract, not the compute.

## Product audit (state as of 2026-07-26)

**Real:** 960-line CLI (`new`, `dev`, `deploy`, `inspect`, `logs`, `doctor`), chat template, D1 provisioning + migrations, versioned JSON output, tests, lockfile design.

**Gaps a YC reviewer will find:**
1. Surface-to-substance ratio: full marketing site, six named products, five are roadmap. Shrink the site, grow the CLI.
2. `plan` and `drift` — the actual differentiation — are specced but not built. Without them it's a Wrangler wrapper.
3. Koomen's stated hard problems (auth & permissions, secure sharing by nontechnical users) = Door + sharing, currently unbuilt. Solving one visibly beats platform breadth.
4. No users yet. The pattern for who gets in (Limrun, Kernel): 2–3 named customers + revenue velocity.

## Mac VM idea — rejected, reasons on record

- **Limrun (lim.run) is YC Spring 2026**, solo founder (Muvaffak Onuş), customers: Replit, Rork, Momentic. They deliberately sell Mac *capabilities* (remote Xcode builds, streamed iOS simulators) via API — not raw VM rental. That's a tell: raw Mac rental is a commodity with a licensing headache. First interview question would be "how are you not Limrun?"
- **Apple macOS Tahoe SLA (verified from the PDF):** Apple hardware only; max 2 VMs per Mac; leasing only for "Permitted Developer Services" (CI/dev); **24-hour minimum lease period**. Always-on personal-agent hosting (OpenClaw) is a licensing gray zone Apple could squeeze anytime.
- **OpenAI cleared the board:** Peter Steinberger joined OpenAI (early 2026); Cirrus Labs (Tart/Orchard, the best macOS virtualization stack) joined OpenAI's Agent Infrastructure group April 2026, shut Cirrus CI, relicensed Tart/Orchard permissively. Validation of the thesis + warning OpenAI ships it first-party.
- Real demand exists (OpenClaw caused a literal Mac mini shortage; "The Mac mini just became infrastructure" — The New Stack), and the one real wedge is "Clawbox as a service" (~$50–80/mo managed always-on Macs). But it's a hosting business: no moat, licensing risk, commoditizing fast (Macly, RentaMac, Roundfleet, Oakhost all racing to the bottom). Economics are fine (mini pays back ~5–6 months at Scaleway rates) but it's not venture-scale without the software/distribution layer.
- Founder-market fit points to Tarantula (networking/cloud background), not Mac fleet ops.

## YC framing playbook

**Don't lead with "agent-native cloud platform"** — modal application this cycle. Suggested one-liner:

> "Coding agents can build small software, but deploying and sharing it is still built for humans. Tarantula is the cloud agents operate directly: one versioned JSON contract to plan, deploy, inspect, and drift-check a complete small app — hosting, data, auth — and share it with your team like a Google Doc."

Application structure:
1. **Wedge first:** deterministic contract for unattended agent operation. Killer demo: Claude Code, empty folder → deployed internal tool with login → shared with a teammate, zero dashboard clicks. Publish an **agent-success-rate benchmark** (works N/N times unattended) — nobody else publishes this.
2. **Solve one RFS hard problem visibly:** build Door v0 (login + share-with-email) before Library/Switchboard/Loops. Sharing-with-auth is the "Google Doc" moment. `plan`/`drift` + Door **is the whole pitch** — cut everything else.
3. **2–3 real users before applying.** Small companies running one real internal tool, or an agent-product company deploying through Tarantula. (Limrun got in solo, one batch ago, with named customers.)
4. **Don't apologize for the Cloudflare layer.** Precedent: Heroku (YC W08, AWS layer, ~$212M exit), Supabase (S20), Porter (S20, "turn your AWS account into Heroku"). Garry Tan: "2024: The Year the GPT Wrapper Myth Proved Wrong." The axis is: does the abstraction unlock users the raw platform can't serve?
5. **Security angle:** the Supabase MCP injection incident is the canonical case for scoped, contract-mediated access over broad conversational MCP. "The safe way to let agents touch production" may be the most durable differentiator.

**Risks to state plainly:** Railway ships this positioning with 100x resources by Q4 2026; Vercel shipping agent-deploy fastest; Cloudflare (VibeSDK + $5 floor) could absorb the layer; Supabase could commoditize any contract by shipping one. Counter: speed, small-company focus (not platform teams), contract + auth combination none of them owns.

**YC context:** solo founders ≈ 11% of recent batches, higher traction bar, but Limrun proved it in this space. W25: 25% of batch had 95% LLM-generated code. Jared Friedman: vertical agents "10x bigger than SaaS." Diana Hu: "AI is the new operating system."
