# Security

Status: mixed

Implemented: credentials stay in Wrangler; account mismatch, lock-name mismatch, and unlocked name collisions fail before mutation; the D1 binding is stable; chat input is validated; posts have size, rate, and bounded-retention guardrails; user text is safely rendered; public access is explicit.

Not implemented: private sharing, roles, vaulted third-party credentials, approval binding, independent security review, or compliance reports.
